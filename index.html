评分指南

SCORAD = A/5 + 7B/2 + C

oSCORAD = A/5 + 7B/2（去除主观症状 C）

  • A（Extent）：AD 炎症性皮损占体表面积百分比，0–100
  • B（Intensity）：6 项客观体征之和（红斑、水肿/丘疹、渗出/结痂、抓痕、苔藓化、干燥），每项 0–3
  • C（Subjective）：瘙痒 + 睡眠影响，各 0–10

严重度分层：＜25 轻度；25–50 中度；＞50 重度（常用临床/研究分层）

代表区域：选择能代表该体征整体严重程度的典型区域，不应单纯选择最严重皮损。

Dryness：应在非炎症性皮肤区域评价。

回顾期：瘙痒/睡眠影响评价最近 3 天 / 3 夜。
